# 需要实现的需求

## 工作流管理

区别于项目管理的页签，单独实现一个工作流管理的页签

工作流的概念: 包含产品送检完整的生命周期，包括 送检 → 威胁分析 → 白盒分析 → 黑盒分析 → 完成

工作流管理页签参照项目管理页签，从上到下依次是

- 小的仪表盘，统计工作流数据，包括工作流总数，项目类型分布的圆饼图，分别根据每个工作流项目威胁分析、白盒分析和黑盒分析三个类型进行分类

- 搜索框和新建工作流的buttom，新建工作流的按钮逻辑和新建项目的按钮逻辑基本类似，只是工作流填写完项目名称和简介后，要依次选择威胁分析、白盒分析和黑盒分析上传的压缩包和技术栈和agents编排包（其中白盒分析为必选，黑盒分析和威胁分析为可选），新建成功后在数据库中存储新的工作流数据，并会在项目中分别依次创建三个类型的项目，填充工作流中输入的数据

- 工作流卡片，工作流卡片区别于项目卡片，一个工作流会占据一行，可以看到工作流完整的五个流程点，通过一条直线上的五个点表示。其中，送检的点下方是创建工作流的时间，威胁分析、黑盒分析、白盒分析的下方是具体的技术栈，选择的agent包和简略的skill列表，完成下方也是具体时间。工作流的卡片支持按钮包括查看详情、编辑、启动和删除

## 工作流卡片按钮使用

- 详情功能：暂不实现

- 编辑功能：可支持新建工作流时填写的参数

- 启动功能：可指定威胁分析、白盒分析或黑河分析进行启动

- 删除功能：删除工作流，并删除关联的项目数据
